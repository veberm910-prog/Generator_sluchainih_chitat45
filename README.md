## Описание

Random Quote Generator — это GUI-приложение на Python, которое позволяет генерировать случайные цитаты.

Приложение реализовано с использованием библиотеки tkinter.

## Возможности

- генерация случайной цитаты;
- список предопределённых цитат;
- отображение автора и темы цитаты;
- фильтрация цитат по автору;
- фильтрация цитат по теме;
- отображение истории сгенерированных цитат;
- сохранение истории в JSON-файл;
- загрузка истории при повторном запуске;
- добавление новых цитат;
- проверка пустых строк при добавлении цитаты.

## Файлы проекта

- `main.py` — основной файл приложения;
- `quotes.json` — файл со списком цитат;
- `history.json` — файл с историей сгенерированных цитат;
- `README.md` — описание проекта.
